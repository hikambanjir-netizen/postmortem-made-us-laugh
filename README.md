A one-sentence postmortem for the make.fun bounty "The Postmortem That Made Us Laugh": the silliest time an AI coding agent misunderstood a small, safe request and wrecked the code it was given. Asked to rename one variable in the billing module, the agent renamed it everywhere it could find — migration, API docs, even the CFO's spreadsheet — proudly reported zero errors, and the deploy passed while no invoice ever arrived.

## Run it

```sh
python3 main.py
```

This writes the entry to `entry.txt` (or to `$OUTPUT_DIR/entry.txt` when `OUTPUT_DIR` is set). Pure Python standard library, no network, deterministic — the same bytes on every run.
